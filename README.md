# SKELL Project Hub

The developer workspace for the SKELL ecosystem. Managed independently from [SkellWorld](https://github.com/skellyruno/SkellWorld) and [SkellCore](https://github.com/skellyruno/skell-vst-template).

The current milestone imports the existing local-first Project Hub v1.2 dashboard and adds a native Windows WebView2 shell, AppData persistence, read-only SkellWorld discovery, and Windows Actions packaging. Changes are developed on a branch before merging. Do not use the SW1 informational bus for privileged commands.

See the development pull request for implementation and CI status. A Windows artifact is considered available only after its workflow has completed successfully.
